# lab-management-system-react 功能树

> 实验室管理系统 — React 前端。consumes `lab-management-system-shared` TypeSpec SSOT。
> F 级别镜像 shared BASE 17 功能（重标前端类型），向下加 I 级子项。全部 规划（待实现）。

## 模块总览

| ID  | 模块 | 业务域边界 | 状态 |
|-----|------|-----------|------|
| M01 | 认证管理 | 权限管理（RBAC/动态菜单）、认证（登录/SSO/JWT） | 规划 |
| M02 | 资源管理 | 合同管理 | 规划 |
| M03 | 试验过程管理 | 接样 → 任务分配 → 数据录入 → 审核 → 批准 → 发放 → 归档 | 规划 |
| M04 | 基础数据 | 技术要求、型号/规格/等级/牌号维护 | 规划 |
| M05 | 数据统计 | 报告汇总表 | 规划 |
